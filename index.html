About these examples

One musical passage. Different spatial arrangements.

Signal path

The original is a stereo sum of the same labeled MoisesDB stems supplied to SceneUpmix in mid/side format. These are stem-based examples, not source-separation outputs. The model predicts object metadata for every layout and style combination.

Playback

Spatial outputs use second-order Ambisonics decoded to 11 virtual loudspeakers and rendered binaurally with KEMAR HRIRs. Excerpt durations are shown beside each song. Headphones are recommended; perceived height and externalization vary between listeners.

Reproducibility

All 16 versions per song are generated offline by the same checkpoint and served as cached audio, not live inference. A common gain per song prevents clipping without matching loudness between conditions. These curated examples are not a listening test or a representative performance estimate.
