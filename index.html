Two dimensions of production intent

Layout defines the role-based arrangement. Style changes its spatial presentation. The same musical objects are retained in all 16 combinations.

Layout Where objects are arranged

Band stage
Central voice, bass and drums; guitar and keys on opposite sides, with drums farther back.
Orchestral stage
Role-based rows: strings toward the front, winds in the middle and percussion farther back.
Studio balanced
A closer arrangement with central anchors and a wider lateral placement of guitar and keys.
Immersive ambient
Stable voice and bass, with selected accompaniment and ambient roles placed higher.

Style How the arrangement is presented

Intimate / dry
Smaller distance, narrower objects and less diffuse energy.
Natural stage
The layout's baseline distance, object width and diffuseness.
Concert hall
Greater distance, broader objects and a larger diffuse contribution.
Immersive live
The largest distance, width and diffuseness settings; additional height for selected roles in the immersive layout.

These are declared authoring presets, not reconstructions of a measured venue. Only roles present in each passage contribute; perceived height and externalization depend on the listener and playback.

About these examples

One musical passage. Different spatial arrangements.

Signal path

Slakh supplies native mono instrumental stems; MoisesDB supplies stereo stems from recorded music. The original is the sum of the same stems supplied to SceneUpmix in mid/side format at 44.1 kHz; mono stems have a zero side signal. These are stem-based examples, not source-separation outputs. Full-passage encoding and temporal pooling produce one static metadata scene for each layout and style combination.

Playback

Spatial outputs use direct SAF Binauraliser rendering with KEMAR HRTFs, magnitude/ITD interpolation and fixed diffuse-field equalization. Linked left/right object signals and object-derived early/late routes are rendered without an intermediate Ambisonic decoder. Audio is 44.1 kHz, 24-bit stereo. The original mix has no HRTF filtering or EQ. Headphones are recommended; perceived height and externalization vary between listeners.

Reproducibility

The sixteen conditions per song are cached renders. The editor renders only the voice in real time using SAF afSTFT and the same prepared KEMAR HRTFs, mixed with fixed accompaniment. Neither path runs model inference in the browser. A common gain per passage prevents clipping without matching loudness between versions; HRTF equalization is fixed. These curated demonstrations use a separate playback renderer from the formal listening study, whose stimuli and results are unchanged.
